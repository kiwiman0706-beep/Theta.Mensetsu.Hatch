# Theta Mensetsu Hatch 0.2.0

- **Android版（ネイティブ）**：`ThetaMensetsuHatch-0.2.0.apk`。Googleの書類スキャナーで紙の履歴書を切り抜いて取り込み、Gmail・ファイル・Googleドライブの「共有」からPDFを直接取り込み。GoogleアカウントはPlay開発者サービスで許可（ログインが1時間で切れない）。PC版と同じGoogleドライブの Theta Vault で同期。
- **手書きメモ（PC・Android・ブラウザ）**：スタイラス対応（筆圧で線の太さが変わる、ペンで書き始めると指・手のひらはスクロールだけ、ペンの消しゴム・ボタンで消せる）、4色・太さ・マーカー、元に戻す／やり直し、罫線・方眼・無地。画像（Obsidianで表示）と線のデータ（あとで書き足せる）を保存し、Geminiで文字に起こせます。
- 採用手続きのチェックリスト（健康診断・免許の持参など）、紹介会社の記録。
- 修正：履歴書を1人分取り込んだあと、その人の画面が開かなかった。

Android版をGoogleとつなぐには、Google CloudにAndroid用のOAuthクライアント（パッケージ名 `jp.yaegaki.theta.mensetsu` と、アプリの初期設定ガイドに出るSHA-1）を作ってください。

未確認：実機（Android）での書類スキャナー・Googleの許可・カメラ／マイク・共有からの取り込み、ペンの筆圧（Sペン・Surfaceペン・Wacomなど）。
