# Theta Mensetsu Hatch 1.0.5

- **勤務の希望（シフト）**：応募者の画面に「勤務できる曜日（月〜日・祝）」「勤務できる勤務帯（日勤・早番・遅番・夜勤・当直・オンコール）」を押して付け外しできる欄と、「時間帯・日数など」（編集から）を足しました。一覧のカードにも出ます。履歴書の本人希望欄に書かれていれば、Gemini の読み取りで入ります。
- **AIの見立て**：応募者の画面の「AIの見立て」→「良い点・懸念点・質問を作る」で、採用にあたっての良い点・懸念される点（確認したい点）・面接での質問（ねらい付き）を作ります。何人かまとめては、一覧の「選ぶ」→「AIに頼む・やり直す」。モデルも選べます。
  - AI に渡すのは職歴・資格・志望動機・本人希望・勤務の希望・通勤・面接メモ・録音の要約だけです（氏名・年齢・性別・住所・連絡先は渡しません）。
  - 「公正な採用選考」（厚生労働省）に沿って、本籍・家族・宗教・思想・健康状態などは判断にも質問にも入れないよう AI に指示しています。採否は面接と書類で判断してください。
