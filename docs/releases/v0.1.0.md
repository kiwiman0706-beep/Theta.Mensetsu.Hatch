# Theta Mensetsu Hatch 0.1.0

最初の版。名刺管理アプリ Theta Meishi Hatch を元に、医療機関の採用面接の管理用に作り直しました。

- 履歴書（PDF・画像・カメラ撮影）を Gemini で読み取り、応募者として登録。顔写真を自動で切り出してサムネイルに
- 職種別の表示・絞り込み（職種は自由に追加）、選考状況・面接日時・評価・採否の記録、面接予定のカレンダー
- 学歴・職歴・免許資格を1行ずつ編集・表示
- 面接の録音と文字起こし・要約、面接メモ、履歴書以外の書類の管理、採用後の職員評価
- 採用手続きのチェックリスト（健康診断・免許の持参など。ひな形は変更可、Obsidianでもチェック可）、紹介会社の記録
- 通勤時間・費用の概算（Gemini＋Google検索）と乗換案内へのリンク
- Google連絡先：アカウント選択・ラベルで名刺や普段の連絡先と分けて登録
- PC版がGoogleドライブと直接同期（項目単位のマージ、削除はゴミ箱へ、安全停止）。PC版は応募者を別ウインドウで開ける
- すべて Obsidian で読める Markdown（Theta Vault）

未確認（実際のGoogleアカウント・PC・Gemini で試す必要があるもの）：Google ログイン、Drive への実際の同期、連絡先ラベル、Geminiでの履歴書・録音の読み取り精度、Windows/Mac のインストーラー、PCのカメラ・マイク。
