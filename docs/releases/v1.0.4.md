# Theta Mensetsu Hatch 1.0.4

- **モデルを変えて AI でやり直す**：応募者の「…」→「モデルを変えてAIでやり直す」。履歴書の読み取りか顔写真の切り出しを、モデルを選んでやり直せます（ふだんのモデルは変わりません）。読み取り直した結果は「要確認」になり、確認してから保存します。
- **一覧で何人かを選んでまとめてやり直す**：リストの「選ぶ」→ 応募者を押して選ぶ（「表示中を全部選ぶ」も）→「AIでやり直す」。
- **メモを一覧にも出す**：面接メモの 📌 を押すと、そのメモがリストのカードにも出ます（Obsidian では本文の先頭が 📌）。
- **顔写真を押すと「顔写真」の画面**：顔写真がある人も、丸い顔写真を押すと「自分で切り出す」「切り出し直す」「外す」を選べます（写真の拡大はその画面で写真を押す）。
- 並べ替え（「評価が高い順」＝☆の多い順など）を覚えておくようにしました。
