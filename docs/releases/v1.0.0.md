# Theta Mensetsu Hatch 1.0.0

Theta Hatch シリーズの決まりに合わせた版です。

- **新しいアプリ ID `app.thetahatch.mensetsu`、シリーズ共通の署名鍵。** 0.2.0 まで（`jp.yaegaki.theta.mensetsu`）とは別のアプリとして入ります。Vault（Googleドライブ）で同期していれば、新しいアプリで Google にログインして同期を始めると応募者が戻ります。戻ったのを確かめてから古いアプリを削除してください（同期していない人は、先に古いアプリで同期を始めてください）。
- **Windows も別のアプリとして入ります**（appId の変更）。新しい版で応募者が見えるのを確かめてから、「アプリと機能」で古い Theta Mensetsu Hatch を削除してください。
- **まとめて書き出す・読み込む（zip）**：応募者のノートと、履歴書の画像・PDF の原本・顔写真・書類・録音・手書きを 1 つの zip に。zip を開けば Obsidian でそのまま読めます。読み込みは足すだけで、読み込む前に件数を表示します。ほかで作った zip も読めます（形式は `docs/IMPORT_FORMAT.md`、確かめるツール `desktop/scripts/check-import.js`）。PC はウィンドウに zip をドロップ、Android は「共有」から zip を渡しても読み込みます。
- **Android：更新はハブに頼む**（メニュー →「更新を確認」。Theta Home Hatch／KidsHome Hatch が無ければ Releases を開く）。**共通設定**：ハブから Gemini のモデル・Google アカウントを受け取り、Gemini API キーは「Home Hatch の Gemini APIキーを使う」で受け取れます。
- 修正：一部の画面の表示（お知らせの行）が出ないことがあった。

未確認（実機）：Home からの入れ替え、ハブの設定の受け取り、Android の書類スキャナー・共有からの取り込み、大きな zip の書き出し・読み込み。
