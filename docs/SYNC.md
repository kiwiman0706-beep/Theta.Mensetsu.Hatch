# 同期のしくみ

PCでの作業が中心で、複数のPC（とブラウザ版）で同じ応募者を扱う前提の作りです。

## 置き場所

```
マイドライブ/Theta Vault/
├── .theta/trash/            ← 削除した応募者のノート（消さずにここへ移す）
└── Mensetsu/
    ├── Applicants/          ← 1人1つのMarkdown「氏名（職種）.md」
    └── _files/              ← 履歴書の画像・PDF原本・顔写真・録音・書類
```

各PCは手元にも同じ形のフォルダ（`書類/Theta Vault` など）を持ち、オフラインでも動きます。

## 2つの方法（PC版）

| 方法 | 内容 |
| --- | --- |
| **アプリがGoogleドライブと直接同期（既定・おすすめ）** | Drive API で同期。Googleドライブ（パソコン版）は不要。ログインはPCが覚えているので裏で動く |
| フォルダの同期に任せる | Theta Vault フォルダを Googleドライブ（パソコン版）・OneDrive などで同期している場合。アプリは同期しない |

## いつ同期するか

- 応募者を変更してから約5秒後
- 3分ごと（アプリを開いている間。ウインドウを閉じてもトレイにいる間は続く）
- ウインドウに戻ったとき（前回から30秒以上たっていれば）
- アプリを終了するとき（最大15秒）
- メニューの「今すぐ同期」、ホーム右上の「同期 12:34」を押したとき

ホームの右上に状態（同期中／最終同期の時刻／⚠）が出ます。

## 判定

| 状況 | 動作 |
| --- | --- |
| 片方だけ変わった | 変わった方を採用 |
| 両方で変わった | **項目ごとにまとめる**：片方だけが入れた項目は両方残す。同じ項目を両方で違う値にしたときは新しい編集を採用し、もう一方の値は面接メモに「（同期）…」として残す。メモ・録音・書類・評価・画像は両方の分を残す |
| 送ろうとした瞬間に別のPCが保存した | 上書きせず、次の回（15秒後）にまとめ直す |
| 一方で削除・もう一方で編集 | 編集を優先（消えない） |
| 削除 | ドライブ・各PCとも `.theta/trash/` に移す（元に戻せる） |
| 一度に多くのノート（既知の30%超かつ5件超）が見当たらない | フォルダの移動・アカウント違いとみなして**同期を止める**（何も消さない） |
| 別のGoogleアカウント・作り直したフォルダ | 前回の記録を使わず、IDで突き合わせて安全にまとめる |
| Obsidianで書き換えた・新しく書いたノート | 取り込む（新しいノートにはIDを書き足す） |

編集画面で保存するときは、**その画面で変えた項目だけ**を保存します。編集中に別のPCが面接日時を入れても、保存で消えません（画面に「別の端末でも更新されました」と出ます）。
