# 初期設定（Gemini と Google）

## 1. Gemini APIキー

1. https://aistudio.google.com/apikey でAPIキーを作ります。
2. **請求先アカウントを設定してください**（Google AI Studio の「請求」または Google Cloud の「お支払い」）。無料枠のままだと、送った履歴書・録音がGoogleのサービス改善に使われることがあります。
3. アプリのメニュー →「Gemini APIキー・モデル」に貼り付けて保存。モデルは `gemini-2.5-flash`（既定）で十分です。

費用の目安（Gemini 2.5 Flash）：履歴書1人（2〜4ページ）で1円前後、30分の面接の文字起こしで数円〜十数円、通勤の概算は1回数円（Google検索を使うため）。

## 2. Google Cloud（同期・Google連絡先を使うとき、1回だけ）

アプリの メニュー →「Google連携の初期設定ガイド」にも同じ手順があり、各画面を開くボタンが付いています。

1. https://console.cloud.google.com/projectcreate でプロジェクトを作る（Gemini のキーを作ったプロジェクトでも可）。
2. **Google Drive API** と **Google People API** を「有効にする」。
3. 「Google Auth Platform」（OAuth同意画面）→「開始」：アプリ名「Theta Mensetsu Hatch」、対象「外部」。
4. 「対象」→「テストユーザー」に、使うGoogleアカウントを追加（連絡先を別のアカウントにするなら両方）。
5. **同じ画面で「アプリを公開」（本番環境）にする**。テストのままだと、PC版のログインが7日で切れます。自分たちだけで使うので審査は不要です。ログイン時に「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」で続けます。
6. 「クライアント」→「クライアントを作成」：
   - **PC版**：種類「**デスクトップ アプリ**」。出てきた「クライアントID」と「クライアント シークレット」を、アプリのメニュー →「Googleアカウント」に貼り付け。
   - **ブラウザ版**：種類「**ウェブ アプリケーション**」、「承認済みの JavaScript 生成元」に `https://kiwiman0706-beep.github.io` を追加。「クライアントID」をブラウザ版の「Googleアカウント」に貼り付け。
7. アプリで「Googleアカウント」→「ログイン」。ブラウザが開くので、**使うアカウントを選んで**許可します。

## 3. 同期を始める

メニュー →「同期」→「アプリがGoogleドライブと直接同期」→「同期を始める」。
マイドライブに `Theta Vault/Mensetsu/` ができ、2台目以降のPCも同じアカウントでログインして「同期を始める」だけで同じ内容になります。

## 4. Google連絡先

メニュー →「Google連絡先への登録」：

- **ラベル名**（既定「面接応募者」）と、職種ごとのラベル（「面接応募者・看護師」）。名刺アプリ（Theta Meishi Hatch）や普段の連絡先とはラベルで分かれます。
- **登録先のアカウント**：「Googleアカウント」で「連絡先は別のアカウントに登録」をオンにすると、採用用のアカウントなどに分けられます。いちばんはっきり分けたいときは、採用専用のGoogleアカウントを作ってそこに登録する方法がおすすめです。
- 名前の後ろに「（看護師 応募者）」を付けるか、顔写真を連絡先の写真にするか、読み取ったら自動で登録するか。
- 選考が終わったら「不採用・辞退の人の連絡先を削除」（応募者の記録は残ります）。

連絡先に送るのは氏名・ふりがな・電話・メール・住所・職種・応募日・面接日時だけです。面接メモ・評価・学歴などは送りません。
