# Theta Mensetsu Hatch

医療機関の職員採用の面接を管理するアプリです。事前に届く履歴書（PDF・画像・紙）を取り込むと、Geminiが読み取って応募者ごとに整理します。
名刺管理アプリ **Theta Meishi Hatch** を元にしていて、同じ「Theta Vault」（Obsidianで開けるMarkdownのフォルダ）にデータを置きます。

## できること

| | |
| --- | --- |
| 履歴書の取り込み | PDF・画像の選択、PCの画面へドラッグ＆ドロップ、フォルダから一括、**PC・スマホのカメラで撮影**。同じファイルは二重に取り込みません |
| 読み取り（Gemini） | 氏名・ふりがな・生年月日・連絡先・応募職種・**学歴・職歴・免許資格**（1行1件）・志望動機・本人希望など。本籍・家族構成・健康状態など職務に関係のない事項は抜き出しません |
| 顔写真 | 履歴書に貼られた写真を自動で切り出し、一覧のサムネイルとGoogle連絡先の写真に |
| 職種別の表示 | 看護師・准看護師・介護職・医療事務…（一覧は自由に追加・変更。編集画面で新しい職種を直接入力してもよい）。職種ごとのタイル、職種での絞り込み |
| 選考の管理 | 書類受付→面接予定→面接済み→内定→採用／不採用・辞退・保留、面接日時、評価（★5段階）、**採否決定日・理由・本人への連絡の記録**、今日の面接、面接予定のカレンダー |
| 面接の記録 | 面接メモ、**録音（PCのマイク）と Gemini による文字起こし・要約**（話者：面接官／応募者） |
| 書類 | 履歴書以外の書類（職務経歴書・免許証の写し・卒業証明書・紹介状・健康診断書・雇用契約書など）を種類つきで人ごとにまとめる |
| 通勤 | 勤務先の住所を設定すると、Gemini＋Google検索で**通勤時間・運賃・定期代を概算**。乗換案内・Googleマップへのリンク |
| 採用後 | 入職日・配属先、**職員評価**（日付・期間・評価者・評価・所見）を積み重ねる |
| Google連絡先 | **登録するアカウントを選べる**（同期と別のアカウントも可）。**ラベル「面接応募者」「面接応募者・看護師」**で名刺や普段の連絡先と分ける。名前の後ろに「（看護師 応募者）」。選考後に不採用・辞退の人の連絡先をまとめて削除 |
| 同期 | PC版はアプリが**Googleドライブと直接同期**（変更直後・3分ごと・ウインドウに戻ったとき・終了時）。同時に編集しても項目ごとにまとめ、食い違った値はメモに残す。詳しくは [`docs/SYNC.md`](docs/SYNC.md) |
| PC版の別ウインドウ | 一覧で **Ctrl＋クリック**（または詳細画面右上のボタン）で、応募者を別ウインドウで開いて並べられる |
| Obsidian | すべて `Theta Vault/Mensetsu/Applicants/氏名（職種）.md` に1人1ファイル。Obsidianで閲覧・編集してもアプリに反映されます（[`docs/MENSETSU_VAULT.md`](docs/MENSETSU_VAULT.md)） |
| 書き出し | CSV（Excelで開ける。全員・今の絞り込み・1人） |

## 版

| フォルダ | 中身 |
| --- | --- |
| `desktop/` | **PC版（Windows / Mac）**。Electron。トレイに常駐し、Vaultフォルダを直接読み書き・Googleドライブと同期。使い方は [`desktop/README.md`](desktop/README.md) |

## はじめかた

1. [Releases](https://github.com/kiwiman0706-beep/Theta.Mensetsu.Hatch/releases/latest) から PC版を入れる（Windows：`ThetaMensetsuHatch-Setup-<版>.exe`、Mac：`.dmg`）。
2. メニュー →「Gemini APIキー・モデル」でAPIキーを入れる（**有料の請求先を設定したプロジェクトのキー**を使ってください。下の注意を参照）。
3. 「取り込む」で履歴書のPDFを選ぶ（または画面にドラッグ＆ドロップ）。
4. 複数のPCで使う・Google連絡先に入れるときは、[`docs/SETUP.md`](docs/SETUP.md) の手順でGoogle Cloudに1回だけ登録します（無料・10分ほど）。

## 個人情報について

- 応募書類は機微な個人情報です。データは利用者のPC・ブラウザと、利用者のGoogleドライブだけに置かれます（運営者のサーバーはありません）。
- 読み取り・文字起こし・通勤の概算では、画像・音声・住所を Google の Gemini API に送ります。**無料枠のAPIキーでは、送った内容がGoogleのサービス改善に使われることがあります。** 請求先アカウント（有料）を設定したプロジェクトのAPIキーを使ってください。
- 面接の録音は、応募者の同意を得てから行ってください。
- 選考後の保管期間・廃棄は施設の規程に従ってください（削除した記録は `Theta Vault/.theta/trash/` に移るので、完全に消すときはそこも削除します）。

Theta Hatch シリーズ共通の約束は [`docs/THETA_HATCH_SPEC.md`](docs/THETA_HATCH_SPEC.md) を参照してください。
